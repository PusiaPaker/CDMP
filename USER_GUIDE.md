# Pandata User Guide

## Welcome to Pandata

Pandata is a project workspace where you can keep your project information in one place. You can sign in, create projects, upload files, add people to a project, and update basic project settings from the website.

This guide walks through a simple first-time workflow.

## Quick Start

### 1. Sign in

When you open Pandata, you will land on the login page.

- Enter your username and password, then click `Login`.
- If available on your site, you can also choose `Sign in with Google`.
- If you do not have an account yet, click `Register` and create one first.

After signing in, you will be taken to your dashboard.

## Dashboard Basics

Your dashboard is the main starting point.

- It shows your projects.
- You can click any project card to open it.
- The left sidebar gives you quick access to:
  `Dashboard`, `Calendar`, and `New Project`
- When you open a project, the sidebar also shows that project's sections:
  `Home`, `Calendar`, `Files`, `People`, `Visualizations`, and `Settings`

## Tutorial: Create and Set Up a Project

### 2. Create a project

From the dashboard:

1. Click `New Project` or `Create Project`.
2. Enter a `Project Name`.
3. Add a short `Description`.
4. Click `Create Project`.

You will be taken into the new project workspace.

### 3. Upload project files

To add files to your project:

1. Open your project.
2. Click `Files` from the project page or sidebar.
3. Click `Upload Files`.
4. Choose the file from your computer.
5. Submit the upload.

Once uploaded, the file will appear in the project's file list.

Pandata is designed to store common project materials, so this is a good place for things like spreadsheets, documents, reports, and reference files.

### 4. Add people to the project

To add people, open the `People` section inside the project.

In Pandata, people are added by importing a spreadsheet rather than typing them in one by one.

1. Click `People`.
2. Click `Import CSV/XLSX`.
3. Choose your spreadsheet file and continue.
4. On the `Map Columns` screen, match your spreadsheet columns to the fields Pandata needs.
5. Click `Import Data`.

For the people import, the most important columns are:

- `Name`
- `Job Title`
- `Role`

You can also include:

- `Email`
- `Phone`

After the import finishes, the People page will show the assigned people for that project.

### 5. Change simple project settings

To update basic project details:

1. Open the project.
2. Click `Settings` in the sidebar.
3. Review the project information page.
4. Click `Edit Project`.
5. Update the project name or description.
6. Click `Save Changes`.

This is the easiest place to make simple updates after the project has already been created.

## A Simple First-Use Example

Here is a common way someone might use Pandata for the first time:

1. Sign in to the website.
2. Create a project called `Website Redesign`.
3. Upload a planning spreadsheet and a project brief.
4. Go to `People` and import a spreadsheet with team members.
5. Open `Settings` and adjust the project description so it is easier to recognize later.

At that point, your project workspace is ready to use.

## Helpful Tips

- If you are new, start on the `Dashboard` and create one project first.
- Use clear project names so they are easy to find later.
- For people imports, clean up your spreadsheet headers before uploading if possible.
- If a column does not match perfectly, use the column mapping page to connect it to the right field.
- Use `Settings` for simple project updates.

## Things to Keep in Mind

- `Files` is for storing project documents and uploaded materials.
- `People` is for importing and viewing the people connected to a project.
- `Settings` is where you edit project details.
- Some advanced actions, like deleting a project, may only be available to the project owner.

## Summary

The basic Pandata workflow is:

1. Sign in
2. Create a project
3. Upload files
4. Add people by importing a spreadsheet
5. Update simple details in settings

Once those steps are done, you have the core of your project workspace set up and ready to manage.
