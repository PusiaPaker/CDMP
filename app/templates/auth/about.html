About Pandata

Quick Overview

Pandata is a consulting data management platform built to help consultants manage multiple ongoing projects in one place. It features multiple data visualizations tools (timelines, calendar, people, financial, files), and is able to integrate with Google Calendar data. Additionally, Pandata features a PDF report generator, that can be used to create shareable summaries of a project's ongoing state.

How Your Data is Handled

All data uploaded by a user for a specific project (files, manual entries, spreadsheet imports) are only accessible to the project owner, and other users that are explicity given view/edit access. Pandata does NOT share the data with any third party systems. Moreover, Pandata uses your data exclusively to generate visualizations, analysis and project reports. If a user wishes to, a user can completely remove all the data that has been uploaded for any project form Pandata.

Who created Pandata?

The platform was created as part of the Kent State University's Spring 2026 Computer Science Capstone class by João Donaton, Antek Chelstowki, Miles Keffer, Tristian Clayman, and Antonio Chiefallo.
