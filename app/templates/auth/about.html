About Pandata

Quick Overview

Pandata is a consulting data management platform built to help consultants manage multiple ongoing projects in one place. It features multiple data visualization tools including timelines, calendars, people, financial tracking, and file organization. Pandata also integrates with Google Calendar data and includes a PDF report generator for shareable project summaries.

How Your Data Is Handled

All data uploaded by a user for a specific project, including files, manual entries, and spreadsheet imports, is only accessible to the project owner and any users explicitly granted view or edit access. Pandata does not share your project data with third-party systems. Your data is used exclusively to generate visualizations, analysis, and project reports, and project owners can remove it at any time.

Who Created Pandata?

The platform was created as part of Kent State University's Spring 2026 Computer Science Capstone class by Joao Donaton, Antek Chelstowki, Miles Keffer, Tristian Clayman, and Antonio Chiefallo.
